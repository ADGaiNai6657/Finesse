# 论文依据与复现边界

## 来源

主论文：Yucheng Zhang 等，*Finesse: Fine-Grained Feature Locality based Fast Resemblance Detection for Post-Deduplication Delta Compression*，FAST '19，论文集 pp.121–128。

仓库文件：[论文 PDF](../paper/Zhang%20等%20-%202019%20-%20Finesse%20fine-grained%20feature%20locality%20based%20fast%20resemblance%20detection%20for%20post-deduplication%20delta.pdf)。[会议页面](https://www.usenix.org/conference/fast19/presentation/zhang)。PDF 第 1 页为封面，PDF 第 2 页对应论文集 p.121；下文引用同时给出论文集页码和 PDF 页码。

已阅读正文、算法、表格与参考文献列表，并对 PDF 第 4–7 页的公式、算法、图 3 和表 2–3 进行了图像核对。论文引用的其他文献及作者代码尚未作为已核实的实现依据。

## 歧义与缺失

| 问题 | 原文表现 | 处理 |
| --- | --- | --- |
| 子块余数 | 算法 2 只给出 `L/N`，未说明整数除法余数 | D-04 已批准 |
| Rabin 精确定义 | 窗口 48 字节明确，多项式、宽度、初值、位序、边界窗口不明确 | D-05 已由用户改为 GearHash；原 Rabin 参数不再阻塞 |
| SF 字节编码 | 式 (2) 写 Rabin(features)，未规定 feature 序列的字节序等 | D-06 已批准处理原则；Gear 字节编码详见 D-14 |
| 随机参数 | `m_i,a_i` 随机预设，缺少具体值与生成过程 | D-07 已批准参数固定与记录方案；具体表见 D-15 |
| 图 3 文字编号 | 第二大值对应的 SF 在正文误写为 SF2；图中标为 SF1 | D-08 已批准；按图及排序描述使用 SF0、SF1、SF2 |
| 匹配细节 | “共享一个 SF”未完整规定跨槽匹配、同键多个基块、FirstFit 遍历顺序 | D-09 已批准跨槽比较 |
| DCE 矛盾 | §5.1 写压缩后/压缩前，但又说越高越好；表 3 也把更高值解释为更好 | D-03 已批准同时保留两种明确命名的指标 |
| 系统实现 | 分块上下限、Xdelta 版本、链深度、负收益处理、缓存单位等未给全 | 分块 D-16，Xdelta/单层/回退 D-22～D-24 已批；缓存/磁盘仍 D-13 |

用户已明确批准以 GearHash 替换 Rabin，并复用 FastCDC 的 CDC。上表保留原论文事实；实现规格采用 Finesse-Gear / NTransform-Gear 标识，不把替换后的速度或匹配结果当作原论文的直接复现。

## D-22～D-24 内存 Delta 阶段的依据边界

再次核对 §5.1（p.125 / PDF 6）：论文明确先精确去重、FirstFit、400MB LRU 和 Xdelta，但没有指定版本、级别、二级压缩、链深或负收益规则。本项目经人类批准采用固定 xdelta 3.2.2 后续修复提交、level6/Adler32/无二级压缩、Raw-only 基块、深度1、payload 严格正收益回退，见 [15](15-xdelta-pipeline-proposal.md)。这些是批准的工程取舍，不是补写的论文事实。

本版存储为可恢复进程内存池，没有论文的磁盘基块读取与400MB LRU，也未做原始六数据集或稳定端到端系统吞吐复现。每算法构造/恢复一次属于 D-24 质量验收；论文/原 SF 五轮协议不能用于描述这次单次实验。
